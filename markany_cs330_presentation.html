Feasibility

Technical, Economic & Operational Feasibility.

Technical
  • CPU Inference: ONNX Runtime ~200 ms/frame — no CUDA required.
  • Browser Capture: WebRTC getUserMedia — no server camera drivers.
  • Dual Persistence: Supabase PostgreSQL + SQLite3 offline fallback.
  • Verified Suite: 16/16 unit tests in 0.43 s.
Working Prototype Built
Economic
  • $0 Licensing: 100% open-source React 19, Flask, InsightFace, SQLite/Supabase.
  • $0 Hardware: No biometric kiosks, RFID readers, or GPUs.
  • Reuse Assets: Existing classroom webcams & student phones.
  • Near-Zero Ops: Free-tier Supabase + local SQLite.
Zero Hardware / License Cost
Operational
  • Timetable Ingest: Regex parser reads existing portal schedules.
  • Lecture Fit: < 2.5 s one-click group capture for 50 students.
  • Human Loop: Faculty override before final lock.
  • Submit Ready: .xlsx / .csv exports for ERP handoff.

Performance & Scalability

  • Commodity 4-core CPU inference — no GPU bottleneck
  • DB queries < 50 ms under normal load
  • Stateless bearer tokens + client-side WebRTC
  • Scales across concurrent classrooms

Security & Privacy

  • Non-invertible 512-D embeddings only
  • Live frames stay in volatile RAM, then discarded
  • Active 3D anti-spoofing (Δ ≥ 0.12)
  • Salted PBKDF2 SHA-256 + signed tokens

Reliability & Usability

  • Automatic Supabase → SQLite3 failover
  • Strict idempotency on attendance writes
  • 1500 ms thermal/battery frame throttle
  • Responsive UI from mobile to 4K

ERD + Limits

Schema Reality & Engineering Constraints.

01

CPU-Only

No CUDA on faculty laptops.

Mitigation: Quantized ONNX ~200 ms/frame
02

WebRTC Context

Cameras blocked on insecure HTTP.

Mitigation: HTTPS or localhost
03

Lighting > 150 lux

Harsh backlight reduces contrast.

Mitigation: Multi-pose + override
04

~330 MB Weights

First-run buffalo_l download.

Mitigation: Local ~/.insightface cache
05

Client Capture

Server never opens OS cameras.

Mitigation: Base64 JPEG REST payloads
06

macOS Quirks

Port 5000 AirPlay clash.

Mitigation: Permanent port 5050
