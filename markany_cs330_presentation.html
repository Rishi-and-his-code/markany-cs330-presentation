Feasibility

Technical, Economic & Operational Feasibility.

Technical
  • CPU-only ONNX: ~200 ms/frame on Intel i5 / Apple Silicon — no CUDA required.
  • Browser WebRTC: getUserMedia eliminates server camera driver issues.
  • Dual Persistence: Supabase PostgreSQL + SQLite3 offline fallback.
  • Test Suite: 16/16 unit tests passing in 0.43 s.
Economic
  • $0 Licensing: 100% open-source — React 19, Flask, InsightFace, SQLite/Supabase.
  • $0 Hardware: Eliminates biometric kiosks, RFID readers, and CUDA GPUs.
  • Reuse Assets: Existing webcams & student phones become capture devices.
  • Low Ops Overhead: Free-tier Supabase cloud DB with SQLite3 offline fallback runs on existing faculty laptops.
Operational
  • Timetable Fit: Regex portal parsing plugs into university routines.
  • One-Click Group: < 2.5 s single-click classroom capture.
  • Human-in-Loop: Present/Absent overrides before finalization.
  • Ready Export: Submit-ready .xlsx / .csv reports.

Four Core Functional Modules.

01
UC-04

Biometric Enrollment

Captures 3–5 multi-angle face samples; SCRFD enforces single face; stores unit-normalized 512-D ArcFace vectors (‖e‖2 = 1.0).

02
UC-05, UC-06

Live & Group Marking

1500 ms live webcam overlay + batch group-photo recognition of 40–50 faces (≥ 24×24 px) with archived BLOB evidence.

03
UC-07

3D Liveness Check-In

Timed mobile self-marking (open_until) with 14-frame head-turn (Δ ≥ 0.12) that also verifies the face matches the logged-in student (REQ-SELF-4).

04
UC-08, UC-10

Audit & Reporting

Roster sheet with match confidences, manual toggles (manually_set = 1), irreversible session lock, and in-memory .xlsx/.csv export.

Enforced Business Rules (BR-1 – BR-7)

BR-5

Cosine Decision Margin

Match accepted iff a · b ≥ 0.38; otherwise flagged Unknown.

BR-6

Duplicate Arbitration

If 2 faces match 1 student, highest confidence claims ID; secondary becomes Unknown.

BR-4 · BR-2 · BR-3

Idempotency & Time Windows

UNIQUE(student_id, session_date, session_id) → max 1 mark; writes blocked outside active open_until.

BR-1 · BR-7

RBAC & Audit Integrity

Faculty-only writes via PBKDF2 SHA-256 + 30-day tokens; manual toggles stamped manually_set = 1.

Constraints & Risk
Limitations

Engineering Constraints & Mitigations.

01

CPU-Only Execution

No dedicated CUDA GPU on standard faculty laptops.

MITIGATION: Quantized ONNX Runtime (~200 ms/frame).
02

WebRTC Secure Context

Browsers block webcam access on insecure HTTP origins.

MITIGATION: HTTPS or localhost / 127.0.0.1.
03

Ambient Lighting (> 150 lux)

Harsh backlighting or dim halls reduce facial contrast.

MITIGATION: Multi-pose enrollment + manual review override.
04

Initial Weight Cache (~330 MB)

First launch needs internet for buffalo_l weights.

MITIGATION: Cached locally in ~/.insightface/ for offline runs.
05

Client-Side Capture Only

Server cannot directly open OS camera drivers.

MITIGATION: Browser getUserMedia + Base64 JPEG REST payloads.
06

OS Runtime Quirks (macOS)

Port 5000 AirPlay clash & Homebrew expat linking.

MITIGATION: Permanent port 5050 + run-backend.sh wrapper.
